# -RK3588-AI-AI-
本作品基于RK3588芯片打造多模态AI陪伴仿生手，围绕手势操控、视觉识别、智能语音三大能力，搭载MediaPipe手势追踪、NPU加速YOLO11n目标检测、通义千问全模态大模型对话系统。系统采用感知-理解-执行三层架构，采集视音频信号后，在端侧完成AI推理，经由串口驱动仿生舵机机械手，配合TTS语音发声。基于PyQt5搭建交互界面，采用多进程、多线程架构规避RKNN线程限制，合理调度摄像头硬件资源，支持语音播报随时中断。   实测手势识别帧率超25FPS、延迟小于50ms，左右手识别无误；物体检测帧率10-15FPS；语音整体响应小于8秒，识别准确率95%以上。作品主打儿童社交启蒙训练，还可用于留守儿童情感陪护、老人居家看护，把轻量化端侧AI技术转化为具备社会实用价值的普惠智能陪护产品。
